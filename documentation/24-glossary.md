# Glossary

**Status:** Baseline  
**Owner:** Product / Engineering

## 1. Product and Domain

| Term                          | Meaning                                                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Academic year**             | The school session, e.g. April 2027–March 2028. Enrollment, fees, attendance, exams, and timetable are scoped to it. |
| **Admission number**          | School-assigned permanent identifier for a student. Unique per school and never reused.                              |
| **Alumni**                    | A former student who has completed or left the school.                                                               |
| **Class**                     | A grade level, e.g. Class 8. Belongs to an academic year.                                                            |
| **Section**                   | A subdivision of a class, e.g. 8-A. Students are enrolled in a section.                                              |
| **Roll number**               | Position or identifier within a section, usually assigned by the school.                                             |
| **Enrollment**                | The link between a student and a class/section for one academic year.                                                |
| **Guardian**                  | A parent, relative, or legal guardian responsible for a student. A student may have multiple guardians.              |
| **Primary guardian**          | The main contact for communication and usually the fee payer.                                                        |
| **Student**                   | A learner enrolled in the school.                                                                                    |
| **Staff**                     | Any employee: teaching or non-teaching.                                                                              |
| **Teacher assignment**        | The mapping of a teacher to a section and subject for an academic year.                                              |
| **Class teacher**             | The teacher responsible for a section’s roster, attendance, and coordination.                                        |
| **Subject**                   | A taught area, e.g. Mathematics.                                                                                     |
| **Elective**                  | An optional subject chosen by a student.                                                                             |
| **Timetable**                 | The weekly schedule of periods, subjects, teachers, and rooms for a section.                                         |
| **Period**                    | A time slot in the school day.                                                                                       |
| **Holiday**                   | A non-working day when attendance is not marked.                                                                     |
| **Attendance session**        | One attendance record set for a section, date, and session type (full day, morning, afternoon).                      |
| **Half-day**                  | A student present for part of the day; treatment depends on school policy.                                           |
| **Excused absence**           | An absence with an approved reason, such as leave.                                                                   |
| **Detention**                 | A student not promoted to the next class.                                                                            |
| **Transfer certificate (TC)** | A document issued when a student leaves the school.                                                                  |
| **Admission enquiry**         | An initial expression of interest before a formal application.                                                       |
| **Application**               | A formal admission request with student and guardian details.                                                        |
| **Conversion**                | Turning an admitted application into a student and enrollment.                                                       |
| **Onboarding**                | Configuring a school and importing its data before go-live.                                                          |
| **Go-live**                   | The date a school starts using the ERP as its system of record.                                                      |
| **Hypercare**                 | Intensive support during the first weeks after go-live.                                                              |
| **Pilot**                     | An early school using the product before general availability.                                                       |
| **Beta**                      | The June 2027 pilot release.                                                                                         |
| **GA (General Availability)** | The October 2027 production release for paying schools.                                                              |
| **Post-GA**                   | Work scheduled after October 2027.                                                                                   |
| **Tenant**                    | An isolated customer space; in this product, a school.                                                               |
| **Organization**              | A trust or group that owns one or more schools.                                                                      |
| **Membership**                | A user’s role and status within a school.                                                                            |
| **Impersonation**             | Time-bound, audited support access to a school account.                                                              |
| **Entitlement**               | A feature or limit enabled by a school’s plan.                                                                       |

## 2. Academic and Exams

| Term                     | Meaning                                                                                       |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| **Term**                 | A division of the academic year, e.g. Term 1, Term 2.                                         |
| **Exam**                 | An assessment event with subjects, max marks, and dates.                                      |
| **Exam subject**         | The configuration of a subject within an exam: max marks, pass marks, theory/practical split. |
| **Formative assessment** | Ongoing assessment during teaching.                                                           |
| **Summative assessment** | Assessment at the end of a term or year.                                                      |
| **Marks**                | Score obtained by a student in a subject.                                                     |
| **Max marks**            | Maximum possible score.                                                                       |
| **Pass marks**           | Minimum score required to pass.                                                               |
| **Theory / practical**   | Components of a subject with separate marks.                                                  |
| **Internal assessment**  | School-assessed component, distinct from a board exam.                                        |
| **Grade**                | A band label derived from marks or percentage.                                                |
| **Grade band**           | The range of percentages mapped to a grade.                                                   |
| **GPA / CGPA**           | Grade point average; used by some boards.                                                     |
| **Percentage**           | Marks obtained divided by total marks, times 100.                                             |
| **Result status**        | Pass, fail, absent, exempt, or withheld.                                                      |
| **Exempt**               | A subject the student did not take and which is excluded from totals.                         |
| **Co-scholastic**        | Non-academic assessment areas such as art, sports, or conduct.                                |
| **Report card**          | The published document showing marks, grades, attendance, and remarks.                        |
| **Publish**              | Making results visible to parents.                                                            |
| **Reissue**              | Creating a new version of a published report card.                                            |
| **Rank / percentile**    | Comparative position; off by default.                                                         |
| **Board**                | The examining authority: CBSE, ICSE/CISCE, or a State board.                                  |
| **CBSE**                 | Central Board of Secondary Education.                                                         |
| **ICSE / ISC**           | Indian Certificate of Secondary Education / Indian School Certificate.                        |
| **State board**          | A state-level examination board.                                                              |
| **Academic coordinator** | Staff member responsible for exams and academic scheduling.                                   |
| **Exam coordinator**     | Staff member who configures exams, locks marks, and publishes results.                        |

## 3. Fees and Payments

| Term                   | Meaning                                                                        |
| ---------------------- | ------------------------------------------------------------------------------ |
| **Fee head**           | A category of fee, e.g. tuition, transport, lab, exam.                         |
| **Fee structure**      | The set of fee amounts for a class, category, and academic year.               |
| **Fee structure line** | One fee head and amount within a structure.                                    |
| **Fee assignment**     | The link between a student and a fee structure.                                |
| **Demand**             | The total amount invoiced or due for a period.                                 |
| **Invoice**            | A demand for payment to a student or guardian.                                 |
| **Invoice line**       | A fee head, amount, concession, and net amount within an invoice.              |
| **Due date**           | The date by which an invoice should be paid.                                   |
| **Grace period**       | Extra time after the due date before late fees or escalation.                  |
| **Concession**         | A discount or waiver, by amount or percentage.                                 |
| **Scholarship**        | A concession with a specific purpose or sponsor.                               |
| **Opening dues**       | Amounts owed from before the ERP go-live.                                      |
| **Offline payment**    | Cash, cheque, DD, or external UPI reference recorded by staff.                 |
| **Online payment**     | A payment through Razorpay or another gateway.                                 |
| **Payment allocation** | Applying a payment to one or more invoices.                                    |
| **Partial payment**    | A payment less than the invoice balance.                                       |
| **Advance / credit**   | Money paid ahead of a demand, held for future allocation.                      |
| **Receipt**            | Proof of payment with a unique, gapless number.                                |
| **Gapless numbering**  | A sequence with no missing numbers, required for financial audit.              |
| **Financial year**     | The accounting year, April–March in India.                                     |
| **Credit note**        | A document reducing an amount owed, used instead of editing an issued invoice. |
| **Refund**             | Returning money to a payer, with approval and audit.                           |
| **Settlement**         | The gateway’s payout batch to the school’s bank account.                       |
| **Reconciliation**     | Matching ERP payments, gateway events, and bank settlements.                   |
| **Exception**          | A reconciliation mismatch requiring review.                                    |
| **Chargeback**         | A disputed card payment reversed by the bank.                                  |
| **Gateway fee**        | The payment provider’s transaction fee.                                        |
| **UPI**                | Unified Payments Interface, an Indian real-time payment system.                |
| **Razorpay**           | The payment gateway used at launch.                                            |
| **PSP**                | Payment service provider.                                                      |
| **Cashbook**           | A daily record of cash receipts and payments.                                  |
| **Aging**              | Grouping outstanding dues by how long they have been overdue.                  |
| **Defaulter**          | A student or guardian with overdue fees.                                       |
| **Dues**               | Outstanding unpaid amounts.                                                    |
| **Collection**         | Money actually received.                                                       |
| **Collection rate**    | Collection divided by demand for a period.                                     |

## 4. HR, Payroll, and Statutory

| Term                      | Meaning                                                                      |
| ------------------------- | ---------------------------------------------------------------------------- |
| **Employee code**         | School-assigned staff identifier.                                            |
| **Designation**           | Job title, e.g. Senior Teacher, Accountant.                                  |
| **Department**            | Organizational unit, e.g. Primary, Administration.                           |
| **CTC**                   | Cost to company; total annual compensation including employer contributions. |
| **Basic salary**          | The base component of salary, usually a large share of gross.                |
| **HRA**                   | House Rent Allowance.                                                        |
| **Allowance**             | A recurring earning component other than basic.                              |
| **Gross salary**          | Total earnings before deductions.                                            |
| **Deduction**             | Amount withheld from gross salary.                                           |
| **Net pay**               | Gross minus deductions; the amount credited.                                 |
| **Salary structure**      | The effective-dated set of components and amounts for a staff member.        |
| **Payroll run**           | The monthly computation for a school.                                        |
| **Payroll item**          | One staff member’s computed earnings and deductions in a run.                |
| **Payslip**               | The document showing a staff member’s salary components and net pay.         |
| **LOP**                   | Loss of Pay, a deduction for unpaid leave.                                   |
| **Leave balance**         | Remaining leave entitlement for a staff member.                              |
| **Carry-forward**         | Unused leave moved to a later period, per policy.                            |
| **PF**                    | Employees’ Provident Fund.                                                   |
| **ESI**                   | Employees’ State Insurance.                                                  |
| **PT**                    | Professional Tax, a state-level tax on income.                               |
| **TDS**                   | Tax Deducted at Source.                                                      |
| **HRA exemption**         | Tax treatment for house rent, subject to rules.                              |
| **Statutory export**      | A file for the CA or government portal; the ERP does not file returns.       |
| **Bank transfer CSV**     | A file used to credit salaries through the bank.                             |
| **Arrears**               | Pay owed for a past period, usually after a salary revision.                 |
| **Reversal**              | A correcting entry that cancels a prior payroll or financial record.         |
| **Segregation of duties** | Requiring different people to prepare and approve sensitive actions.         |
| **CA**                    | Chartered Accountant; validates payroll and tax treatment.                   |

## 5. Communication

| Term                      | Meaning                                                                             |
| ------------------------- | ----------------------------------------------------------------------------------- |
| **Transactional message** | A message triggered by an event, e.g. absence, receipt, OTP.                        |
| **Announcement**          | A broadcast message to a group.                                                     |
| **Template**              | A reusable message with variables.                                                  |
| **Variable**              | A placeholder replaced at send time, e.g. `{{student_name}}`.                       |
| **Channel**               | Delivery medium: push, SMS, WhatsApp, email, in-app.                                |
| **Delivery status**       | Queued, sent, delivered, failed, or opted out.                                      |
| **Opt-in**                | Consent to receive a category of messages.                                          |
| **Opt-out**               | Withdrawal of consent for non-essential messages.                                   |
| **Quiet hours**           | A period when non-urgent messages are not sent.                                     |
| **Fallback**              | Sending through another channel if the first fails.                                 |
| **DLT**                   | Distributed Ledger Technology; India’s SMS sender and template registration system. |
| **DLT entity ID**         | The registered identity of the SMS sender.                                          |
| **Sender ID**             | The 6-character header shown on SMS.                                                |
| **Template ID**           | The DLT-approved SMS template identifier.                                           |
| **BSP**                   | Business Solution Provider for WhatsApp.                                            |
| **WhatsApp template**     | A pre-approved message format required by Meta.                                     |
| **FCM**                   | Firebase Cloud Messaging, used for push notifications.                              |
| **Push token**            | A device-specific identifier for push delivery.                                     |
| **Deep link**             | A link that opens a specific screen in the app.                                     |
| **In-app inbox**          | A list of messages retained inside the app.                                         |
| **Resend**                | The email delivery provider.                                                        |
| **MSG91**                 | The SMS provider.                                                                   |
| **Bounce**                | An email that could not be delivered.                                               |
| **Suppression list**      | Addresses or numbers that should not receive messages.                              |

## 6. Security and Compliance

| Term                        | Meaning                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------- |
| **PII**                     | Personally Identifiable Information.                                                  |
| **Sensitive personal data** | Data whose misuse can cause harm, e.g. financial, health, or children’s data.         |
| **DPDP Act 2023**           | India’s Digital Personal Data Protection Act.                                         |
| **Data Fiduciary**          | The entity that determines the purpose and means of processing; typically the school. |
| **Data Processor**          | An entity processing data on behalf of the fiduciary; typically the platform.         |
| **Data Principal**          | The individual whose data is processed; the student or guardian.                      |
| **Sub-processor**           | A vendor engaged by a processor to help process data.                                 |
| **Consent**                 | Free, specific, informed, and unambiguous permission for processing.                  |
| **Notice**                  | The information given about data collection and use.                                  |
| **Purpose limitation**      | Using data only for the stated purpose.                                               |
| **Data minimization**       | Collecting only what is necessary.                                                    |
| **Retention**               | How long data is kept.                                                                |
| **Erasure**                 | Deletion of data, subject to legal retention.                                         |
| **DPIA**                    | Data Protection Impact Assessment.                                                    |
| **Breach**                  | Unauthorized access, disclosure, alteration, or loss of data.                         |
| **DPA**                     | Data Processing Agreement.                                                            |
| **Grievance**               | A complaint from a data principal.                                                    |
| **Authentication**          | Proving identity.                                                                     |
| **Authorization**           | Determining what an authenticated user may do.                                        |
| **RBAC**                    | Role-Based Access Control.                                                            |
| **RLS**                     | Row Level Security in PostgreSQL.                                                     |
| **Tenant isolation**        | Preventing one school from accessing another’s data.                                  |
| **Least privilege**         | Granting only the access needed.                                                      |
| **MFA / 2FA**               | Multi-factor / two-factor authentication.                                             |
| **TOTP**                    | Time-based one-time password used for MFA.                                            |
| **OTP**                     | One-time password, usually sent by SMS.                                               |
| **Session**                 | An authenticated period of use.                                                       |
| **JWT**                     | JSON Web Token; used for mobile access tokens.                                        |
| **Refresh token**           | A long-lived token used to obtain new access tokens.                                  |
| **Token rotation**          | Issuing a new refresh token on each use and invalidating the old one.                 |
| **CSRF**                    | Cross-Site Request Forgery.                                                           |
| **XSS**                     | Cross-Site Scripting.                                                                 |
| **SQL injection**           | Injecting SQL through unvalidated input.                                              |
| **IDOR**                    | Insecure Direct Object Reference; accessing another user’s record by ID.              |
| **SSRF**                    | Server-Side Request Forgery.                                                          |
| **WAF**                     | Web Application Firewall.                                                             |
| **DDoS**                    | Distributed Denial of Service.                                                        |
| **Encryption at rest**      | Encrypting stored data.                                                               |
| **Encryption in transit**   | Encrypting data over the network, e.g. TLS.                                           |
| **KMS**                     | Key Management Service.                                                               |
| **Secret Manager**          | A managed store for credentials and keys.                                             |
| **Penetration test**        | An authorized security assessment.                                                    |
| **SAST / DAST**             | Static / Dynamic Application Security Testing.                                        |
| **SBOM**                    | Software Bill of Materials.                                                           |
| **CVE**                     | Common Vulnerabilities and Exposures.                                                 |
| **ASVS**                    | OWASP Application Security Verification Standard.                                     |
| **Incident**                | An unplanned event that affects confidentiality, integrity, or availability.          |
| **RCA**                     | Root Cause Analysis.                                                                  |
| **Postmortem**              | A blameless review after an incident.                                                 |
